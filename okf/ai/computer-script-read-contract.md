# Summary

Reads return promised shapes or explicit failures, never fabricated empty observations. Typed preflight document/candidate invalidation with no preparation/input returns not_dispatched, seals invocation and adds no completed_actions. [Scripts](computer-use-scripts.md) owns namespace/failure barriers; every read retains privacy/permission/publication checks.

# Contract

## Validation and identity
Validate min/max arity before guest/image/download-cursor dispatch; extras fail SCRIPT_ARGUMENT_ERROR with method/documented_arity. Preserve types/options/empty/zero/null. Validate whole operation before focus/scroll/input; closed diagnostics exclude secrets/page errors. Keys accept characters/documented names/modifiers, not physical Equal. computer_wait defaults0/no settling; legacy waitFor keeps state.

Wait-only browser sequences need no page revision/virtual focus. Mixed sequences bind initial revision through waits/events, reject replacement input and release owned transitions. Delay is not invalidation; missing/malformed observation seals, never fabricates tree. Explicit invalidation-return follows Scripts contract.

Node/text/query/table/attribute/condition/lower faults retain semantic_read/source identity. Whole-page/image reads bind revision through publication; refs bind target/ancestors/main, not unrelated children. text samples innerText/URL/title/frame/document/ref together; combined reads fence same-document routes. Ordinary mutation is not document replacement; new-route/old-data remains source truth for model judgment.

Empty child URL requires exact isolated-frame document.URL with unchanged lifecycle/origin/privacy, never parent/blank allowlist. Bad URL fails without disconnect/malformed response; later explicit read may recover. Retired frames reject input and cannot be reinstalled by fenced inventory; unknown inventory remains unknown. Publication failure retires images, no quiescence/second ledger.

Entry/publication privacy scans are independent. Navigation checks control/destination without old-page reads; timers check control without content/editing. Neither publishes nor cancels takeover. Later reads/input retain privacy; confirmed input stays separate.

## Conditions and navigation
One deadline spans preparation/safety/sampling/cleanup/publication. Check privacy every sample without URL/title rereads. Return requested_state/timeout/elapsed/samples, never readiness. Timeout is data; requireState raises CONDITION_TIMEOUT/seals even caught, retaining prefix. Closed diagnostics retain method/state/time/zero-based operation indexes but no matching text/raw errors. Completed waits need not match.

Only typed document/candidate change discards affected sample under same deadline/privacy latch. Resample from exact lifecycle evidence, never global revision/error wording; retain frame/scope/event/protocol facts. Revalidate original unique query/fixed scope even for absence. Invalid samples are not absent/hidden. Ambiguity/stale ref/root, unknown evaluation/protocol, permission/cancel stop; ordinary reads/input never retry candidate faults.

navigate/back/reload accept commit|domcontentloaded|load and0..30000ms, defaults load/20000. Return command_acknowledged/navigation_stage/wait(state reached|timeout, wait_until, timeout_ms, elapsed_ms). Deadline starts before dispatch; root/loader includes pre-ack events, same-document/download. Timeout permits explicit reads/waits in same namespace; unknown/network acknowledgement, permission/cancel/target change stops. No replay/network-idle heuristic.

## Evaluation and delivery
One evaluate/callFunctionOn checker rejects exceptionDetails/invalid shapes, preserving promised false/zero/empty/null/void. Only confirmed same-document install marks preparation. Later explicit reads may reprepare, never replay effects. Observer readiness is not app readiness.

Evaluation facts retain phase/method/exception|invalid_result. DOMSnapshot validates used fields, allows protocol-empty and omits unavailable offsets. Typed transport invalidation keeps method, never invented codes; unknown stage=internal_error. Activity/results/logs exclude raw exception/stacks/page values; prior output survives except privacy. Help uses observed roles/refs.

Input methods return closed delivery/needs_observation/invalidation, not read/business success. Optional post_action_check unavailable neither revokes acknowledgement nor exposes unchecked content. Private input pauses; permission/cancel/connection/target/cleanup/uncertainty stops. Content-returning edits/legacy images keep publication checks. action_executed confirms completion; preparation_executed requires fresh read without completed click/scroll. Posted/observed counts are not business outcomes; unknown release/delivery/mutation exceptions cannot confirm completion. Closed actionability preserves failed_checks without relabeling prefix. Missing refs yield observation-unavailable/reference_not_retained, not invented change.

Hit facts include point/ancestry/embedding/scroll intersection, no text. Resolve CSS pseudo origin before ancestors/shadow checks; overlays reject without alternate point. Root/OOPIF checks validate known ancestors, not unrelated frames. Text uses Range rectangles, elements/documents native geometry; unsupported measurement fails. connected/rendered/visible/opacity_zero/enabled/editable/receives are distinct. Offscreen text may be visible; transparent rendered targets still need hit ownership. Hover needs no enabled, click does, fill needs editable. Return closed stage/state/bounds.

## Bounded reads
query(limit,cursor) returns loaded authorized AX attributes/count/loss/document/cursor,<=200items/48KiB. Content changes invalidate cursor; retain only returned refs. href keeps relative/query/fragment with credential redaction. Retired linkSummary fails predispatch with precise_attribute_read; explicit attributes preserve query/fragment. Long fields use source reads.

rows selects one table/grid excluding nested tables, retaining header/data/cell roles/refs. Per page<=200rows/48KiB, per row<=200cells/44KiB, cell<=2000Unicode. cells_truncated/text_truncated expose loss; incomplete rows prove no total. Cursor binds full cell content; count covers loaded matches. attribute:string|null and getAttribute:{attribute,value,redacted?} distinguish absent/empty. Nonempty DOM names<=2000chars; values>2000codepoints need source(). URL credentials remain private; native rejects browser-only methods before dispatch.

scroll_progress is return-only requested scope/measured_ref, not wheel receiver. Immediate before/after/offset_changed proves no scroll_effect; unknown=null. Separate preparation/input. Wheel uses clipped/transformed visible intersection/document viewport, checks ancestors/embedding overlays then sends once; not offscreen center/enabled check. Rejection retains preparation, no alternate/replay.

No automatic diff/advisor. read_options is explicitly target-level method_inventory, not per-node ability. root/limit/continuation retains source scope; node detail is not subtree, child_refs/children_truncated describes returned relations. Use snapshot/rows/query/count for collections.
