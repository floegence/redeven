# Boundaries

Results apply only to recorded hardware/path/workload/published versions/fixture and valid intervals. Missing source input invalidates ordinal latency association; missing presentation with complete source input is an adverse result. Later favorable rounds erase neither earlier failures nor uncertainty about cause. Cross-time measurements do not prove causality.

Release/compatibility gates qualify only named contracts, not LAN performance. A reboot creates a distinct fixture identity. Unsupported physical platforms inherit no Linux qualification; hardware decode/photon latency remain unclaimed. Performance never waives security, authorization, input, ordering or recovery.
