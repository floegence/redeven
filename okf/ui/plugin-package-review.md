# Summary

ReDevPlugin owns package inspection, validation and atomic changes. Redeven presents exact source/candidate/permissions for consent. Cancel stops only pre-submit inspection; unknown effects reconcile without replay. Updates preserve layout with fresh slots; only confirmed uninstall removes it.

# Contract

## Updates
One Review update action opens exact intent without mutation/navigation. Official updates immediately show validated release preview, never full-market refresh/external download. Missing preview reads only selected detail for same generation/release. External uses released inspection API.

Confirm full reviewed release ref, metadata/package digests and installed management revision. Changed generation/ref/revision invalidates consent; same-version substitution forbidden. Post-submit refreshes only installed inventory; canceled/superseded reads cannot replace dialog.

Content-sized bounded dialogs retain identity/versions during prep/submit/completion; no tall shell for brief states. Long review scrolls above fixed footer. Show access once with destinations/process/background; technical limits expandable. Closing completion keeps Updates, clears obsolete selection and shows All plugins are up to date when empty.

## External packages
Admins choose compatible public HTTPS, GitHub Release/optional tag or local .redevplugin. Submit source/intent to released inspector; browser never downloads/parses remote packages, chooses trust or fabricates provenance. Failed post-install refresh offers inventory Retry only, never second install.

Lead with verified locale-resolved author/publisher/version; technical IDs never replace available names. Verified state quiet, unverified/blocked/revoked warn. Omit four-step timeline/intro while retaining accessible progress.

Before consent show destinations, host permissions, credentials, processes, background and host methods. Ordinary Worker/plugin-storage methods never become broad delete-content counters; dangerous/unknown effects stay visible regardless of route. Keyboard package details retain declarations/diffs/source/hash/binding. Network has one heading with changes inline; storage/process/background changes stay on rows; removed declarations remain reportable.

Saved-data row uses released security summary, including settings-only/no-Worker packages. Exact Surface/store/operation details collapse. Resource changes mark row; label-only changes do not. Writable Surface resources join sensitive declarations, never host-filesystem permission or automatic grants.

One short checkbox confirms exact package; signature cannot replace consent. Review claims no completed install/grant; enabled state proves no grant. Unknown result retains inspection/reconciliation. Wrap long names/locales, retain mobile targets/fixed footer. External install grants nothing and explains later access management; official install keeps its reviewed-permission flow.

# Boundaries

[Surfaces](plugin-surfaces.md) owns discovery/navigation. Inspection/commit bind released Host identities; no stale candidate, trust-derived permission or uncertain replay.
