# Contract

## Reference drafts
Launcher/Tessiven chips wrap/scroll inside bounded input. @ discovery requires whitespace boundary/collapsed caret, immutable thread cwd or new-thread directory, and bounded global matching for slashless queries. Root failures offer Retry; inaccessible descendants skip within limits. Focus changes color without geometry/shadow shifts and preserves candidate/action focus.

## Origin page

Draft/canonical previews share presentation, not authority.
